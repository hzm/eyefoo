# EyeFoo — 护眼休息提醒

一个住在 Windows 托盘里的极简护眼工具：每工作一段时间，弹出提醒；不理会或推迟次数用完，就进入全屏强制休息，防止你连续盯着屏幕太久。

## 功能

- 默认每 44 分钟提醒一次，可推迟 5 / 8 分钟（最多 3 次），随后强制休息 3 分钟
- 强制休息为全屏黑屏倒计时，前 30 秒不可退出（可在设置中调整）
- 支持暂停 30 分钟 / 1 小时、立即休息
- 多显示器全覆盖；系统休眠时间不计入计时
- 提醒声音可开关，支持开机自启，所有节奏参数可在设置中调整
- 单实例、常驻托盘，几乎不占资源

## 下载与安装

**系统要求：Windows 10 / 11（64 位）**。不支持 Windows 7 / 8——本程序界面依赖的 WebView2 组件微软已于 2023 年起停止支持旧系统。

👉 [点击下载最新版安装包](https://github.com/hzm/eyefoo/releases/latest/download/EyeFoo-Setup.exe)

1. 下载后双击 `EyeFoo-Setup.exe`。
2. 如果出现蓝色的「Windows 已保护你的电脑」提示（程序没有购买代码签名证书，属正常现象）：点 **「更多信息」→「仍要运行」**。
3. 安装过程会自动检测并联网安装 WebView2 组件（大多数 Win10/11 电脑已自带，会自动跳过），请保持联网。
4. 安装完成启动后，会弹出一个引导窗口，告诉你程序在哪里——它没有主窗口，驻留在**屏幕右下角的系统托盘**里。

## 使用

- **右键托盘图标**：暂停 30 分钟 / 暂停 1 小时 / 恢复计时 / 立即休息 / 设置 / 退出
- **提醒弹出时**：可以推迟，也可以不理会，倒计时结束自动进入休息
- **休息界面**：全屏倒计时，右下角「退出休息」按钮在解锁时间后可点击
- **设置**：工作周期、休息时长、提醒等待、推迟次数、声音、开机启动等均可调整

## 卸载

在 Windows「设置 → 应用」或控制面板中找到 EyeFoo 卸载即可。配置文件位于 `%APPDATA%\com.eyefoo.desktop\`，可一并删除。
